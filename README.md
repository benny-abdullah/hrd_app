# hrd_app

Enterprise Cloud HRIS Platform (Mekari Talenta Full Suite Architecture)

## Description

Aplikasi Enterprise Cloud HRIS Platform dirancang untuk pengelolaan sumber daya manusia (Human Capital Management) pada organisasi berskala menengah hingga besar dengan fitur lengkap mulai dari manajemen data karyawan, presensi, payroll, hingga laporan analitik.

## Fitur Utama

- Dashboard Executive dengan metrik korporasi
- Database Karyawan dengan Direktori Master Data
- Presensi Online dengan Geofence & GPS
- Employee Self-Service (ESS) untuk cuti, lembur, dan reimbursement
- Approval Center dengan alur persetujuan bertingkat
- Payroll & PPh 21 TER (PP 58/2023)
- Manajemen Kinerja & KPI dengan 9-Box Grid
- Inventaris Aset & Stok
- Dokumen & Penomoran Otomatis
- HR Helpdesk & Tiket

## Teknologi

- HTML5, CSS3, JavaScript (Tailwind CSS via CDN, Chart.js)
- Single file application (index.html)
